# Xtvshort

Xtvshort is a Telegram Mini App for video streaming.

## Features

- YouTube video player
- Video browsing
- Rewarded ad unlock system
- Telegram Mini App support
- Supabase backend (planned)
- Netlify hosting

## Technology

- HTML, CSS, JavaScript
- YouTube Embedded Player
- Netlify Functions
- Supabase
- Telegram Mini Apps
- Monetag Rewarded Ads
